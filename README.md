# Save_The_Eggs
Better save those eggs, or else.

# How to use:
1. Download the repository as .zip
2. Extract it
3. Run the .exe file (Located in /bin/Debug).

# Game
* The player can set his own playtime.
* The player uses the A and D keys so they move the basket left and right.
* The eggs' speed will increase as the game progresses.
* The objective is to catch as many eggs that are falling as possible.
